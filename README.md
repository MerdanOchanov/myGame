# Scientists World

Геолокационная web-игра на реальной карте мира: игроки — ученые, которые физически исследуют биомы, собирают материалы, создают неизвестные лекарства в доме-лаборатории и выживают под воздействием мировых и локальных событий.

Подробности:
- [Техническое задание](docs/TZ.md) — игровой дизайн, правила, MVP
- [Архитектура](docs/ARCHITECTURE.md) — целевая техническая архитектура, принятые решения, backlog

Текущий код в `src/` — ранний прототип и не отражает финальный дизайн; актуальный список расхождений см. в `docs/ARCHITECTURE.md` (раздел "Текущие расхождения с кодом").

## Стек

TypeScript, Vite, Phaser, Leaflet (client). Backend: Supabase (Postgres + PostGIS, Realtime, Auth, Edge Functions).

## Запуск

```bash
npm install
npm run dev
```
